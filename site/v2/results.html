感知和重建这几步已经能自动跑通

四段视频（胆囊减压、胆囊复位、肝缝合、肺纵隔清扫）都由 agent 自己读文字、看关键帧给点、让 SAM 3 跟踪。器官从椭球出发拟合，胆囊的 4D 拟合 IoU 0.83–0.92，不比 v1 用解剖模板差。器械的刚体模型和掩码重合 0.79–0.92。

物理仿真是干净的，但器官还动得太少

胆囊减压这段，仿真里没有器械非法穿进器官，胆囊也不再陷进背景（v1 每帧有 15–24% 的表面陷进去）。但胆囊跟着器械动的幅度只有重建的三分之一左右，运动解释率刚转正（+0.08）。肝那段的第一次仿真是坏的。

文字确实避免了 v1 的解剖错误

文字解析读出了"胆囊是游离的，只吊在胆囊管和动脉上"和"这一段在减压，有穿刺口"。v1 把胆囊固定在肝床上，把吸引管当成探针，这两个错这次都没有再犯。

对比视频 · 暂定

胆囊复位（20 秒）

  • 器械 agent 和背景 agent 各自独立发现这一段的深度整体偏近约 35%。原因是胆囊一直在翻转，画面里静止的结构太少，原来的求解找不到远距离匹配。
  • 几何 agent 重新求解后（焦距固定为同一视频里另一段求出的值，远距离匹配从 0 增加到 8.4 万对），每帧深度尺度的波动降到和镜头 A 同一水平（0.94–1.04，原来 0.82–1.25）；远距离探针误差的中位数从 224 px 降到 10 px，但这不是严格的留出检验，第 90 百分位仍有 245 px。
  • 新几何还有缺陷：相机是逐帧求解的，有抖动（每帧约 1.2 mm）；器械杆仍有 24% 的采样点落在组织后面（原来 68%）；目前只看过数字，还没有人看过渲染图。器官、器械、背景都要在新几何上重做，上面三维场景里放的还是旧几何的版本。
  • 旧几何上胆囊的 4D 拟合 IoU 是 0.74 / 0.70 / 0.77，体积 28.9 ml。
