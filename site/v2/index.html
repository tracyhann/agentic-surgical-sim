文字引导的器官 4D 重建

新方法的进行中记录。每段手术视频先读它配套的文字，再由一组 agent 分工：定位并分割器官和器械、求相机和深度、从基本几何体拟合器官、给器械建刚体模型、重建可碰撞的背景，最后合成物理场景。下面的三维场景就是重建本身，SAM 3 分割出的每个对象都有自己的三维模型，列在场景下面。拖动旋转，滚轮缩放，右键平移；切到内镜视角可以和真实视频左右对比。

SAM 3 分割出的对象和它们的三维模型

    勾选框控制这个对象在三维场景里显示或隐藏。"按对象着色"下每个对象用这里的颜色画出来。物理仿真只计算主器官，其余对象在"物理仿真"里显示的仍是重建。
    结果轮廓 IoU ↑不切深度 ↑运动解释率 ↑翻转四面体 ↓最大位移
    物理仿真一行来自最近一轮整合；轮廓 IoU 是仿真的器官投影和 SAM 3 掩码的重合（每 10 帧一次）。没有仿真的场景只有 4D 重建一行。

    画面里是什么

    • 主器官：从椭球出发、多视角多帧拟合出来的四面体体，逐帧形变。"物理仿真"播放的是 MuJoCo 算出来的形状。
    • 其他会动的结构（胆囊颈和蒂、三角韧带）：同样的体模型，逐帧形变。管状和膜状结构目前用同一种通用体模型近似。
    • 背景里的小实体：血块、条索、纱布、脂肪、没认出来的器官，各自建成封闭的凸体，静态。
    • 背景表面：所有帧融合出来的静态表面，肝、膈肌、网膜是它上面带标签的区域。
    • 器械：刚体模型，每把绕一个固定的穿刺点（红点）运动，位姿逐帧拟合。
    • 内镜：青色线框是内镜视野，位置和朝向来自多视角联合求解。

    怎么用

    • 拖动旋转，滚轮或双指缩放，右键或双指拖动平移。
    • "几何形状"下最容易看清三维形状；"按对象着色"能分清每个分割对象；"形变热图"显示相对第一帧的位移。
    • 内镜视角下拖动中间的竖线，左边真实视频，右边重建。
    • 空格 播放 / 暂停，← → 逐帧，V 切换视角。

    重建这一步，三段视频都能自动做出来

    agent 自己读文字、看关键帧给点、让 SAM 3 跟踪，再求相机、拟合器官、器械和背景。器官都从椭球出发，不用解剖模板：胆囊的 4D 轮廓 IoU 是 0.79–0.92，肝是 0.84–0.89。器械的刚体模型和掩码重合 0.83–0.92。上面三维场景里的"4D 重建"就是这部分结果。

    从器械运动往前仿真器官的动态：一段部分成立，两段不成立

    胆囊减压这段，仿真干净（没有非法穿插，器官不陷进背景），胆囊跟着抓钳动，但幅度只有重建的三分之一左右，而且只是轮廓对得上：视频里胆囊被抽瘪了，仿真里它还是鼓的。肝这段修好后不再崩坏，但肝是静止的，带动它的呼吸和缝线都不在模型里。胆囊复位这段，仿真里的胆囊几乎不动，游离胆囊的转动没有从物理里算出来。

    卡住的地方是接触

    器械和器官由不同的 agent 分别重建，各自和画面对得上，放到一起在三维里却有冲突：复位段约三分之一的帧里，器械杆落在胆囊模型内部。两者沿视线方向的深度都只准到约 1 cm，而接触物理需要准到约 1 mm。这一条是这次实验最主要的发现，后面单独列了数字和试过的办法。

    对比视频

    肝左叶尖端缝合（14 秒）

    • 原视频其实是 5 个场景，用翻页转场连起来。提示 agent 看图发现了这一点，自动切换检测没查出来。这里用的是最长的连续场景。
    • 肝的 4D 拟合 IoU 0.84 / 0.89 / 0.85。两把持针器 IoU 都是 0.90。这一段是在给之前缝好的一针打结，没有进针。
    • 第 5 轮的仿真是坏的，第 8 轮查到了原因。整合规则把持针器当成抓钳，让它"夹住"了 19 个肝顶点并拖着肝尖走，于是上千个四面体翻转。持针器夹的是针和线，不是组织。规则改成按器械类型判断后，翻转四面体从 1008 降到 0，体积守恒（6.3 / 6.4 ml），轮廓 IoU 从 0.51 升到 0.66。
    • 但肝现在是静止的。重建里肝尖平均移动约 7 mm，带动它的是呼吸和打结时缝线的牵拉，这两样模型里都没有，所以运动解释率是 −0.10。
    • 最后一轮视觉检查的判断：不算有意义的复现。仿真是一个几乎不动的椭球，两把持针器的末端停在空中，没有缝线，没有接触；轮廓对得上只是因为画面里本来就没怎么动。

    第 6–7 轮：物理仿真是负结果

    • 仿真的胆囊质心只动 0.4–2.2 mm，重建里它移动 4–10 mm。轮廓 IoU 0.46（重建本身 0.74），运动解释率 −0.07。
    • 把组织调硬 10 倍后，胆囊不再被器械压皱（翻转四面体 208 → 9），体积守恒，但仍然不跟着动。去掉背景里那块楔形的脂肪实体也没有区别。
    • 这一段里器械全程在推和拨，没有持续夹住胆囊，所以完全靠接触传力。
    • 第 9 轮的诊断：只修接触位置也不够。把每把器械沿视线往内镜方向滑，直到杆不再和重建的胆囊重叠（抓钳 175 帧里滑了 53 帧，中位数 5.9 mm；分离钳 215 帧里滑了 124 帧，中位数 13.0 mm），再重跑仿真。结果和不修一样：轮廓 IoU 0.45–0.46，运动解释率 0.00 到 −0.07。器械大部分时间操作的是胆囊颈和蒂，而它不在仿真的器官模型里。
    • 最后一轮视觉检查的判断：不可用。8 个抽查画面里 4 个明显错。
    主要发现

    器械和器官各自对得上画面，放在一起却有三维冲突

    第 6 轮新加了一个检查，在做任何仿真之前，直接拿重建出来的器械杆去对器官的 4D 模型。规则来自文字：没有声明开口的器械不能在器官内部。

    试过的五种办法都没有解决

    办法结果
    器械拟合里加规则：看得见的地方必在器官前面冲突帧 11 → 9、18 → 18。器械绕固定穿刺点转，每帧没有单独的深度自由度
    器官重拟合：表面不得落在器械杆内，并入胆囊颈冲突还在；胆囊被背景挤成 12.8 mm 厚的薄板。背景 agent 用上一版器官的背面去填看不见的地方，器官再被这块填充挤薄，两个 agent 之间形成了棘轮
    器官重拟合：沿视线把器官表面压到器械后面拟合跑飞，胆囊变成 152 × 136 × 65 mm、696 ml。往远处退并等比放大可以不改变轮廓，优化就顺着这个方向走了
    不重拟合，直接把器官节点推到器械后面每帧要推的距离中位数 13 mm，超过胆囊厚度（21 mm）的一半，推完有 332 个四面体翻转
    反过来移动器械：沿视线滑到不和器官重叠为止（第 9 轮）冲突消除了，但仿真结果不变。说明接触位置只是原因之一

    前四种办法得到的器官模型都没有采用，保留在 organs/gallbladder/_rejected/ 里。

    最后做了一个单参数扫描：把胆囊整体沿视线推远（不改变轮廓），看有没有一个比例能让两把器械都贴着但不穿入。没有。推远 1.3 倍时抓钳不再穿入，但离胆囊 21 mm、从不接触，分离钳仍有 7 帧在里面。所以冲突不是整体尺度问题，是逐帧的、约 1 cm 量级的误差，目前判断不了错在哪一边。

    • 这个镜头单独切成一个片段，用和另外三段相同的流程：相机 7 个关键帧，重投影误差 35.8 → 4.4 px；两把器械各一个刚体模型；淋巴结和脂肪块从椭球出发拟合（4D 轮廓 IoU 0.70 / 0.60 / 0.86，0.6 ml）；清扫面和白色条索是背景表面上带标签的区域。5 个对象都有三维模型，在上面的三维场景里是第四个场景。

    还没做的

    • 接触要和形状一起估计。现在器械和器官先各自定好深度再去碰，误差直接变成穿入或悬空。更可行的做法是把"器械贴在器官表面"当成要估计的状态，和器官的运动一起求。

    • 镜头 A 的胆囊要补上画面外的底部。
    • 肝这类视频需要呼吸运动和缝线，否则没有东西带动器官。
    • 背景 agent 不应该用器官模型去填器官背后，避免两个 agent 互相挤压。
